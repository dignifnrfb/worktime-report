工时助手隐私说明

1. 本软件只在本机运行，本地服务仅监听 127.0.0.1，不接受局域网或互联网设备连接。
2. 软件不包含遥测、广告、远程控制或后台上传功能。每次启动检查 GitHub 正式发布版本；下载安装需要用户点击确认。
3. 网络访问用于公司 OA 页面，以及指定 GitHub 仓库的版本检查和更新包下载；不会把工时内容、账户或登录会话发送给 GitHub。
4. 软件不保存 OA 密码。钉钉扫码后的浏览器会话、个人默认设置、已办缓存、当前账户可见的项目号/项目名称缓存和本机排查日志保存在当前 Windows 用户的本地应用数据目录。日志不含 Cookie、二维码或登录会话，也不会上传。
5. 安装包不包含制作者的姓名、工号、OA 会话或历史工时数据。
6. 卸载时可以选择同时删除本机保存的个人数据。
