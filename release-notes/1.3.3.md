修复“下载成功，确认安装后却没有安装”的问题。

Windows 上直接以分离进程方式启动 PowerShell 时，安装助手可能直接退出，没有执行安装脚本，也没有写入安装结果。直接挂在旧服务下的进程又可能随着旧服务关闭而结束。现在通过独立的隐藏启动进程启动安装助手，确保旧服务退出后继续执行，安装完成后重新打开工时助手。

1.3.2 修复的是安装状态长期等待的提示，1.3.3 修复实际的安装助手启动问题。保留安装包来源、大小与 SHA-256 校验、忙碌期间禁止安装和个人数据保护，不自动重复安装。

已在隔离环境完成真实按钮确认、安装助手执行、覆盖安装、自动重新打开、旧页面恢复和测试数据保留的完整验证。测试安装包由本地响应提供，网络下载单独验证。

如果当前 1.3.0–1.3.2 无法自动安装，请确认没有安装程序仍在运行，然后手动运行本版完整安装包，按原位置覆盖升级一次。旧版的安装启动代码需要由完整安装包替换；个人设置、登录会话、工作日安排和已办缓存保留。
